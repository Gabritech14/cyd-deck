CYD Deck

Web flasher for the Freenove ESP32-S3 2.8" board (FNK0104). Firmware v0.2.0. Flash dal browser per la scheda Freenove ESP32-S3 2.8" (FNK0104). Firmware v0.2.0.

Your browser can't talk to USB devices. Use Chrome, Edge or another Chromium-based browser on a computer (Firefox and Safari don't support Web Serial). Il tuo browser non può parlare con i dispositivi USB. Usa Chrome, Edge o un altro browser basato su Chromium da computer (Firefox e Safari non supportano Web Serial).
This page has to be opened over HTTPS. Questa pagina va aperta in HTTPS.

Nothing to install on your computer: everything happens in the browser. Non devi installare niente sul computer: fa tutto il browser.

How it worksCome si fa

  1. Plug the board into your computer with a USB-C cable that carries data (some cables only charge).
  2. Click Connect & install and pick the board from the list (usually "USB JTAG/serial debug unit").
  3. On a first install, say yes to erasing the device. When updating, leave it unticked to keep your Wi-Fi settings.
  4. Wait for it to finish (about a minute). The screen shows an empty grid: it's waiting for the PC.
  5. Install the desktop app and run it: see the README.
  1. Collega la scheda al computer con un cavo USB-C che porti anche i dati (alcuni cavi caricano soltanto).
  2. Clicca Collega e installa e scegli la scheda dall'elenco (di solito "USB JTAG/serial debug unit").
  3. Alla prima installazione accetta di cancellare il dispositivo. Per un aggiornamento lascialo vuoto, così tieni le impostazioni del Wi-Fi.
  4. Aspetta che finisca (circa un minuto). Sullo schermo compare una griglia vuota: è in attesa del PC.
  5. Installa il programma per il PC e avvialo: trovi tutto nel README.

If the board isn't foundSe la scheda non si trova

  1. Hold BOOT, press and release RESET, then let go of BOOT, and try again.
  2. On Linux your user needs access to the serial port: group uucp (Arch) or dialout (Debian/Ubuntu), then log out and back in.
  3. Close anything else using the port, including the CYD Deck app itself.
  1. Tieni premuto BOOT, premi e rilascia RESET, poi lascia BOOT e riprova.
  2. Su Linux il tuo utente deve poter usare la porta seriale: gruppo uucp (Arch) o dialout (Debian/Ubuntu), poi esci e rientra.
  3. Chiudi tutto quello che usa la porta, compreso il programma CYD Deck.
